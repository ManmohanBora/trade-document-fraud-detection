Auditor-in-the-Loop Architecture

Pipeline Architecture Breakdown

This systems diagram illustrates the complete ingestion and analytical path of cross-border trade documentation:

  • Document Ingestion: Handles Commercial Invoices, Bills of Lading, and Customs Declarations via FastAPI REST endpoints.
  • OCR & Normalization: Multilingual optical text extraction paired with DPI scaling and morphological pre-filtering.
  • Parallel Analytics Branches:
    • Image Analytics (OpenCV · YOLO · ResNet): Inspects stamp perimeters, signature strokes, letterhead logos, and pixel-level Error Level Analysis (ELA) tampering.
    • NLP / Document Understanding (LayoutLMv3 · Transformers): Spatially extracts structured entities (amounts, HS codes, container numbers, trading entities).
  • Multimodal Feature Fusion: Synthesizes spatial text evidence with forensic visual artifacts, generating cross-modal anomaly flags.
  • Storage & Compliance Interface: Stores auditable JSONB records in PostgreSQL and renders interactive metrics via Streamlit + Plotly.
